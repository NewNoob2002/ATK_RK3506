# P4 原应用源码来源

- 原 View/资源/工具来源：`HC32F460xE_Arduino/Simulator/App`，提交 `37b069a0e76061dbac07e9345e653d1796945bac`；保留许可说明。PageManager 后续已加固路由、卸载和边界，不再是仅头文件适配。
- 本分支移植 `FASTSHIFT/X-TRACK/Software/X-Track/USER/App/Utils/DataCenter`（MIT），源提交 `c42b8e5605e50838f4c0c9828385948fa33ab485`。适配 LVGL include、Account 注册有效性/容量/序号、发布时订阅者删除、多个订阅者销毁清理、参数/分配边界与公共日志；未引入 X-TRACK HAL。
- 每个路由页在自身目录拥有 Controller、View、Model。Model 独占 Account 并订阅/拉取/接收数据、通知服务和 StatusBar；构造函数不注入 DataProc，已删除共享 PageModel。`Common/DataProc` 仅初始化处理 Accounts 并提供 `DataProc::Center()`；路由在 Utils/DataCenter，行为在处理模块/SystemService。
- `P4App` 组合十页、StatusBar 与通用输入。原 Shutdown 路由更名为 SystemDash，不保留旧路由别名；新增 SystemSettings。SystemDash/SystemInfos/SystemSettings 通过各自 Model 通知将状态栏移至屏外，SystemDash 及其 Settings 子页统一使用全屏；StatusBar 仅在工作页等明确需要的页面显示。沿用 HC32 的 500ms y=−26↔0 动画（显示 ease-out、隐藏 overshoot），不切换根对象 hidden flag；反向从当前位置继续，同向不重启。只有页面展示请求控制移动，数据刷新不擅自改变位置。
- RK3506J 真正产品输入是两路 GPIO HIGH/LOW 电平，不是键盘 F/P 或 evdev/ADC 按键；Function/Power 只是逻辑职责名。Function GPIO 单击 NEXT/+1、双击 BACK/CANCEL；Power GPIO 单击 ENTER/选择、双击 COMMIT。主机 SDL 与 UI 测试不使用该绑定或双击等待：方向键/滚轮换焦点，Enter/中键按下与松开（Startup 长按 2 秒启动，其余页面短按选择），Esc/右键返回，Ctrl+Enter 提交，左键指针交互和 Q 退出恢复。当前测试板仍用 V+/V-/MENU/ESC，可用额外 KEY_ENTER 直接测试 Commit；量产 GPIO chip/line、有效 HIGH/LOW、输入/pull 配置与时序尚未验证，不默认映射。平台读取电平后按确认的有效电平归一化 pressed，再在 UI 线程调用 on_key()/poll_keys()；读取失败应取消输入并报错。linux_button_read_keys() 仅为可选 evdev 测试辅助，不能用于 GPIO 产品接入。界面不添加测试键提示。
- SystemDash 为 Power/Settings/Return 三卡；其 Settings 子页同样保持 StatusBar 隐藏（88px 宽、7px 间隔），Function 单击循环三项、Power 单击选 Return 使用 PageManager::pop() 返回上页，主机 Enter/指针同样有效；StarMap 隐藏根页黄色焦点外框，保留焦点与点击返回能力；电源弹窗默认 Cancel，Shutdown/Reboot 仅产品 Power GPIO 双击（主机直接 Commit）进入 SaveConfig 后调用模拟 SystemService，重复执行被 token 拦截，提前返回取消事务。按用户确认移除手动日期入口与编辑器及页面草稿逻辑；SystemSettings 仅语言内联切换、禁用 Wi-Fi 与可见 Back，Function 单击循环语言/Back、Power 单击选择，不要求 Up/Down；双击 Function 仍可返回。原 RAM 日期服务/校验契约保留但无手动 UI 入口。没有系统时钟写入、持久化或 Linux/设备关机重启命令。
- 新绘 SystemDash Power/Settings/Return 图像在 `Resource/img/img_src_system_dash_power.c` / `img_src_system_dash_settings.c` / `img_src_system_dash_return.c`，分别为原生 40px 菜单图像，Power 另有 24px 弹窗版本；Return 的可编辑源为 `system_dash_return.svg`。采用 8-bit alpha 掩码、主题重着色，合计像素数据 5376 字节。旧 16px 图像保留供其他页使用，不再在 SystemDash 放大。最新英俄截图见 out/ui-pages/SystemDash/three-tile-return-starmap.png；native-icons-settings.png 是原两卡历史截图。
- 状态由 DemoStatus/StatusService 提供明确标为 DEMO 的自有快照；所有 LVGL、Account、输入、计时器在主线程执行，未来异步生产者需主循环投递。`Utils/Log` 提供运行时级别、可替换 sink、stderr 默认输出与有界格式化；PageManager/DataCenter 使用同一 API，普通投递日志为 DEBUG。
- 本分支按情境切页：Startup/SystemLoading/Dialplate 与 SystemInfos 淡入，设置/菜单水平推进，StarMap/SaveConfig 从下向上进入；Back 反向退出，时长 280–360ms。PageManager 在缓存页重入时复位未动画轴/透明度，坐标 getter 读取与 setter 一致的对齐偏移，避免跨轴返回残留偏移或底对齐 StarMap 跳动；Oswald 支持英俄，Rajdhani 仅用于数字。Startup 在主机 Enter/中键/左键或测试板 MENU 长按 2 秒后进入 SystemLoading；短按、指针移出和窗口失焦取消。重复按下不重启计时，跨页松开不触发下一页。产品开机长按/电源时序保留为未来平台接入点，不将单击伪装为开机。两个开机阶段均用现有 PageManager::replace() 替换前页，Dialplate 为工作根页，Back 不再进入 Startup/SystemLoading；模拟 SaveConfig 完成按动作区分：Off 在未切断系统电源时调用 PageManager::reset_root("Pages/Startup")，清空旧历史并重建待机根页；Reboot 回到工作根页 Dialplate。进度和完成计时在 did_appear 后启动，避免主机长帧撞上未结束的切页。
- Startup 默认隐藏 StatusBar，did_appear 后未完成启动长按则 10 秒滑入；短按取消不重置该延迟，离页删除定时器。SystemLoading 一律上滑隐藏状态栏，先展示 Logo 800ms，220ms 淡入带旋转齿轮/圆环的 System Initialization；3 秒模拟配置/服务/GNSS/网络/收尾五阶段，100% 停留 200ms 后转绿色勾选 System Ready，保持 1 秒再淡入 Dialplate。默认使用 img_src_SystemLoading_XYZ.c（仍导出 img_src_startupLogo）；既有 RGK_LOGO_USE/MIDDLE_LOGO_USE 分别选 RGK/Neutral 文件。黑/灰/橙/绿界面按参考图包含阶段标题、辅助文案、8px 进度条、百分比、Step N of 5、五个连接圆点与 GNSS RTK Receiver 页脚；文字/激活点淡入，Ready 颜色和齿轮→勾选过渡 220ms。英俄用 Oswald（Rajdhani 没有 % 字形）。全程标 DEMO，System Ready/服务可用仅为用户要求的模拟效果，不代表真实硬件就绪；中途离开任何阶段均清理计时器/动画。拼图见 out/ui-pages/Boot/current-flow.png、steps-flow.png；实际主机帧动画见 boot-en.gif/boot-ru.gif。
- 主机测试扩为 9 项，含框架日志/生命周期、页面 Model 数据、直接逻辑操作与双语布局；除直接主机操作外，新增归一化 GPIO 逻辑样本回归，检查两键 Settings 循环焦点和 Back、SystemDash 三项循环及 Return 返回/重新进入，保持电源操作未执行，并检查 StarMap 无外框；不访问真实 GPIO、不改变 SDL 输入适配。SDL 构建及 dummy-video 退出已验证；详细命令与截图路径见 [UI 计划](../../docs/UI_PAGES_OPTIMIZATION_PLAN.md)。本分支未 ARM 构建、部署或硬件验收；既有 [P4 板端记录](../../docs/P4_APPLICATION.md) 不替代本次验证。
